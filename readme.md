# YaСut

### Проект "YaСut" 
 
### 1. Общее описание:  
Приложение-сервис укорачивания ссылок с интеграцией облачного хранилища (API Яндекс Диска).
Цель проекта - предоставить пользователям короткие ссылки для более наглядного и лаконичного размещения на различных ресурсах. 

### 2. Как запустить проект:

Клонировать репозиторий и перейти в него в командной строке:

```
git clone 
```

```
cd yacut
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Создать в директории проекта файл .env с четыремя переменными окружения:

```
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DB=sqlite:///db.sqlite3
```

Создать базу данных и применить миграции:

```
flask db upgrade
```

Запустить проект:

```
flask run
```

### 3. Использование: 
Функциональная составляющая проекта реализуется посредством отправки запросов на эндпоинты:
- /api/id/ — POST-запрос на создание новой короткой ссылки;
- /api/id/<short_id>/ — GET-запрос на получение оригинальной ссылки по указанному короткому идентификатору.

Дополнительная функция YaCut — загрузка сразу нескольких файлов на Яндекс Диск (IO-bound задача по асинхронной загрузки файлов реализована по адресу /files) и предоставление коротких ссылок пользователю для скачивания этих файлов.

### 4. Структура проекта: 
Основная логика проекта реализована в приложении yacut (отвечает за [API](yacut/api_views.py), логику [веб-интерфейса](yacut/views.py) и взаимодействие с [внешним API](yacut/yadisk.py) Яндекс Диска).

### 5. Технологии: 
Проект построен, как веб-приложение c REST API, для взаимодействия с приложениями посредством HTTP-методов и предоставляет ответы в формате JSON. Для работы проекта используются сторонние [библиотеки](/requirements.txt). Логика проекта реализована на Python v3.12.7 посредством использования библиотек веб-фреймворка Flask.
